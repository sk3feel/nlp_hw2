# BART106M

## Подготовка и обучение

Исходные данные: `SlavaYus/tinysms_qa_12m`, revision `b2724689ff079e9c22efd548fe134bfb29036dbb`. Нужны60 файлов `part-00000.parquet` ... `part-00059.parquet` из опубликованного train.

Из папки проекта:

```bash
python prepare_data.py --raw-dir /путь/к/data/train
```

Скрипт создаёт `data/prepared_data.zip`: 5820047 training-пар и1500 validation-примеров после прежних фильтров, split и токенизации. Состав и порядок массивов проверяются по сохранённым хэшам. Готовый архив при повторном запуске проверяется и используется повторно.

Затем откройте `solution.ipynb` и выполните все ячейки. Он обучает модель с нуля, сохраняет90940/96625/102308 и усредняет их. Для продолжения укажите `RESUME`. Основной конфиг рассчитан на A100/BF16; для меньшей GPU уменьшите `physical_batch`, сохранив effective256.

Token-ID массивы совпадают с историческими. Байты ZIP могут отличаться из-за упаковки и сокращённого набора служебных файлов. Старый архив тоже поддерживается.

Код: `prepare_data.py` → `data.py` → `model.py` → `train.py` → `inference.py`. Зависимости: `requirements.txt`; CUDA-сборка PyTorch должна соответствовать драйверу.
